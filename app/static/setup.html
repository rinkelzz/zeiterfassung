3. Automatisch an der Wache

  1. In Kurzbefehle unten auf Automation, dann +.
  2. Ankommen wählen → Ort der Wache suchen und festlegen → Sofort ausführen wählen → Weiter.
  3. Den Kurzbefehl Kommen auswählen.
  4. Zweite Automation: Verlassen → gleicher Ort → Gehen.

Löst das iPhone mal doppelt aus, ist das egal: Wer schon eingestempelt ist, wird nicht zweimal eingestempelt.
